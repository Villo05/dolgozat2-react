# Workshop

Egy kreatív foglalkozásokat és workshopokat szervező vállalkozás webalkalmazását kell elkészítened React és TypeScript használatával.

Az alkalmazásban a látogatók megtekinthetik a meghirdetett programokat, kategória szerint szűrhetik azokat, valamint jelentkezhetnek a kiválasztott foglalkozásra.

Az alkalmazás egyetlen oldalból áll.

A design színei és betűtípusai szabadon megválaszthatók, de az elrendezést a minta alapján kell elkészíteni.  

<img src="assets/minta.png" alt="minta">



## Az oldal működése

Minden programkártyán jelenjen meg a program neve, kategóriája, időpontja, helyszíne, a férőhelyek és a jelentkezettek száma, valamint egy „Jelentkezem” gomb.

Jelentkezés: A gombra kattintva a kiválasztott programhoz tartozó jelentkezők száma eggyel növekedjen az alkalmazás állapotában. A módosítás azonnal jelenjen meg a felületen.

Létszámkorlát: Ha a jelentkezők száma eléri a férőhelyek számát, ne lehessen további jelentkezést rögzíteni.

## Szükséges komponensek

- App - itt kezeld az oldal állapotát vagy a Context-ben. 
- Kartyak - ez tartalmazza az összes kártyát
- Kartya - Egy darab kártya megjelenítése. Itt röténik a kattintás az esemény
